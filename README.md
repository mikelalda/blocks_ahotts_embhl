block_ahotts_embhl
=======================

Moodle block which inserts a Listen button on pages that enable users to listen to content using your own text-to-speech API. The plugin is also available on the official Moodle Mobile App.

Requirements
------------

This plugin requires Moodle 3.0+.


Motivation for this plugin
--------------------------

The block_ahotts_embhl can be used to insert a block with a Listen button into pages to enable your own audio service.


Installation
------------

Install the plugin to the folder
/blocks/readspeaker_embhl

See [https://docs.moodle.org/en/Installing_plugins](https://docs.moodle.org/en/Installing_plugins) for details on installing Moodle plugins

Usage & Settings
----------------

After installing the plugin, it needs to be configured with the base URLs of your own API endpoints for Basque, Spanish and English.


License / Subscription details
-------

This plugin no longer requires a ReadSpeaker license.


Requirements
------------

This block now delegates to your own API endpoints.

Requirements for request parameters and payloads depend on your own API implementation.
